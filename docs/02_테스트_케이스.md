# 테스트 케이스 및 검증 결과

> **상태:** 테스트 설계 완료 / 실행 전. 아래 결과 칸은 실제 실행한 뒤 작성합니다.

## 1. 테스트 개요

### 1.1 테스트 목적

- 필수 기능과 선택 기능 5개의 정상 동작 검증
- 잘못된 입력, 파일 손상 및 중단 상황에서의 안전성 확인
- JSON 파일별 영속성 및 독립 복구 검증

### 1.2 테스트 환경

| 항목 | 실제 환경 |
| --- | --- |
| 운영체제 | 미기입 |
| Python 버전 | 미기입 (요구: 3.10 이상) |
| 터미널 / IDE | 미기입 |
| 테스트 날짜 | 미기입 |

### 1.3 테스트 방법

- 수동 콘솔 테스트와 Python `unittest` 자동 테스트 병행 예정
- 테스트 전 `data/state.json`, `data/scores.json` 백업 후 복구
- 정상 입력, 경계값, 예외, 종료 및 재실행 검증
- 결과 표: `미실행 / PASS / FAIL` 중 하나로 기록
